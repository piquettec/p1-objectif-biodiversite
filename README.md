## Présentation

Le projet Objectif Biodiversité Québec était de faire un site Web qui montre les différentes espèces du Québec et leur statut de protection.
On devait faire 3 pages, la page d'accueil, la page de la liste des espèces et puis la fiche des espèces.

### Description, principaux défis 
Les principaux défis étaient de prendre les informations dans la base de données qu'on à été donnée et de l'intégrer dans le site, de créer les filtres et de faire fonctionner la pagination.

### Liens 
- [URL Github](https://github.com/piquettec/p1-objectif-biodiversite)
- [Les biotiques](https://timunix3.csfoy.ca/~biotique/index.php)

## Mon Processus

### Technologies utilisées

Comme technologie utilisées on utilisé du HTML pour faire la structure des 3 pages, du CSS pour modifier l'apparence du site pour qu'il ressemble au design, le SQL pour prendre les informations des bases de données et le PHP pour afficher les informations de la base de données

### Utilisation de l'IA 

Aucune utilisation de l'Iag a été utilisé pendant l'integration et la programmation du site.

## Rapport de tests

## Bilan des apprentissages
### Quels principaux apprentissages retenez-vous du projet Objectif Biodiversité Québec? 

Ce projet m'a permis de mieux comprendre comment utiliser PHP et SQL ensemble pour afficher des informations provenant d'une base de données.

J'ai aussi appris à utiliser les jointures SQL pour récupérer des informations de plusieurs tables. J'ai pu pratiquer la création de filtres, la pagination et l'affichage dynamique des espèces.

J'ai également amélioré mes compétences en HTML et CSS en intégrant les différentes pages du site.

### Développement continu
Pour mes prochains projets, je souhaite approfondir :

Les connaissances sur le SQL ainsi que le PHP.
Créer des meilleurs filtres pour avoir plusieurs filtre en même temps.
